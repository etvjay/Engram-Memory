# Attribution

Engram Memory is a fresh Hack Hydra submission repository.

This project may interoperate with, benchmark against, or reuse permitted components from the following third-party/open-source projects. Any actual copied or adapted code must retain the source project's license and be identified in the relevant file or commit.

- Repository: `hydra-db/hydradb`
- Role: required open-source graph database substrate for the Hack Hydra submission.
- License: use according to the upstream repository's current license.

- Repository: `xiaowu0162/LongMemEval-V2`

## Evidence policy

Benchmark data, scripts, upstream code, and derived artifacts must retain enough source information to reconstruct provenance, including source repository, commit/release when available, license, local modifications, and the command used to produce derived outputs.
